# kas-smiths-public-archive

A daily-updated archive of publicly visible content from the
[kas-smiths.org](https://kas-smiths.org) Discourse forum — the topics and posts any
logged-out visitor can already see.

This repository is a public, readable JSON mirror of forum topics and posts. It is meant
for open browsing, lightweight analysis, and preserving the visible discussion history in
a simple data format.

## Contents

- `archive/topics.json` — public topics
- `archive/posts.json` — public posts

## Updates

Content is refreshed and committed automatically once a day.
Deleted or edited posts are reflected in future runs, but earlier committed versions remain
visible in this repo's git history.
